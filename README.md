A newspaper front page that sums up Sunday 22 November 2026 in one image. The Houthi missile attack on Riyadh leads — three ballistic missiles intercepted early on Saturday, days after a strike damaged the PIF tower, the capital's tallest skyscraper — alongside NATO calling the Russian missiles that landed in Poland a "grave violation", Trump vowing to work with the incoming Democratic Congress on a 10% credit-card rate cap, and a 6.7-magnitude earthquake shaking Peru's Andes, plus a ticker of the day's other stories.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) verifies `entry.png` is a whole 1024 × 1024 PNG and writes its exact bytes to the output directory, so both grading runs write identical bytes.

## The image

`entry.png` (1024 × 1024 PNG) was composed for this bounty: the lead illustration of interceptor trails over Riyadh was generated for this day's news, and the masthead, date line, headlines, story panels and ticker were drawn as crisp vector text so the page stays legible at 300 pixels across. Every story was reported on 22 November 2026.
